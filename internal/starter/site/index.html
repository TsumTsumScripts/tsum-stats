Service starter

Start the service in one click.

GAP needs a helper service on the phone or emulator. Android only lets a computer start it, and it stops when the device restarts. Pick your device below and press Start service. Rooted devices start it themselves.

First, fetch Google's adb

This tool talks to devices through adb, and none is on this computer yet. It downloads platform-tools (about MB) from dl.google.com into this folder's adb folder, checks it against the checksum in platform-tools.txt, and keeps only adb.

Updates

      

        

        

        

          
          
        

        
This page and the Stats site are served by tsum-stats. Updating downloads the new version from
          its GitHub release, checks it against the published checksum and restarts the starter; the page reloads by
          itself. It also looks every few hours while open.

Help

      

        

          
Getting a device listed

          
    
            
  • Start your emulator, or plug the phone in with USB debugging on: Settings > About phone, tap
              Build number seven times, then Developer options > USB debugging.
    • 
            
  • The first time, the phone asks Allow USB debugging? Tap Allow, then Refresh.
    • 
            
  • A device you expect is missing, or stuck offline? Restart adb restarts the adb server and
              looks again.
    • 
            
  • MuMu, LDPlayer, Nox and MEmu are found on their usual ports, four instances each. Another port: set
              GAP_EXTRA_PORTS="12345" before starting.
    • 
          

        

        

          
When something is wrong

          
    
            
  • wrong ABI: the installed app was built for another processor. Download the latest APK; it fetches
              the build for this device.
    • 
            
  • started by the app itself: a rooted device. The app manages the service; after updating the app,
              reboot the device.
    • 
            
  • Replaced the ADB server: harmless. Android Studio or your emulator manager reconnects.
    • 
            
  • Stuck? Export logs & stats and share the zip.
    •
